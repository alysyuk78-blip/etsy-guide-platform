# Etsy: від нуля до масштабування

Навчальна платформа для продавців з України на базі посібника «Etsy: від нуля до масштабування» та калькулятора економіки магазину.

## Що всередині

- **Покроковий маршрут** — 10 етапів від реєстрації магазину до масштабування, з повним текстом посібника
- **Інтерактивні схеми** — 12 схем у форматі SVG
- **Калькулятор економіки** — 7 робочих аркушів: ціна, перевірка ціни, мито США, реклама, план 12 тижнів, журнал продажів, довідник комісій
- **Глосарій** термінів
- Відстеження прогресу читання (зберігається у браузері)

## Технології

React 19 · TypeScript · Vite · Tailwind CSS

## Запуск

```bash
npm install
npm run dev
```

Збірка:

```bash
npm run build
npm run preview
```

## Структура

- `src/content/` — контент посібника (етапи, секції, глосарій)
- `src/pages/` — сторінки платформи
- `src/components/` — компоненти інтерфейсу, включаючи схеми
- `src/hooks/` — хуки стану та прогресу
